## 📌 Repository Overview
This repository contains the complete workflow of my internship tasks at **CodeAlpha**. The projects demonstrate an end-to-end data pipeline, starting from automated data collection to rigorous cleaning and finally visualization.

---

## 🛠️ Task 1: Web Scraping & Data Collection
**Objective:** Automate the extraction of product data from e-commerce platforms.

* **Description:** Developed a Python scraper using **SerpApi** to collect data on 300+ laptops from Amazon.
* **Technical Highlights:** * Implemented pagination logic to scrape 21+ pages.
    * Extracted complex technical specs (RAM, Disk Size, OS) from nested JSON responses.
* **Output:** `amazon_laptops.csv` (Raw Data).

---

## 🧹 Task 2: Exploratory Data Analysis (EDA) & Data Cleaning
**Objective:** Transform raw, messy data into a reliable dataset for analysis.

* **Description:** Performed comprehensive cleaning on the scraped Amazon dataset to ensure data integrity.
* **Key Actions:**
    * **Data Wrangling:** Handled missing values in "Price" and "Rating" columns.
    * **Type Conversion:** Converted string-based metrics into numerical formats for statistical calculation.
    * **Outlier Detection:** Identified and addressed anomalies in pricing using statistical methods.
    * **Statistical Summary:** Generated descriptive statistics to understand the distribution of laptop brands and features.
* **Notebook:** `Task2_EDA_and_Data_Cleaning.ipynb`

---

## 📈 Task 3: Data Visualization
**Objective:** Communicate data-driven insights through compelling visual stories.

* **Description:** Created a series of visualizations to reveal market trends and product correlations.
* **Visual Insights Created:**
    * **Market Share:** Distribution of laptop brands in the dataset using Seaborn.
    * **Pricing Trends:** Histograms and Box Plots to visualize price ranges across different technical specs.
    * **Performance Correlations:** Scatter plots analyzing the relationship between Price, Ratings, and Disk Size.
* **Tools Used:** Matplotlib and Seaborn for static reporting, with logic structured for BI dashboard integration.
* **Notebook:** `Task3_Data_Visualization.ipynb`
